# 관심기업 데이터 트래커 (텔레그램 알림)

GitHub Actions가 정해진 시간마다 데이터를 확인하고, **새 소식이 있을 때만** 텔레그램으로 보내 줍니다.
내 컴퓨터를 켜 둘 필요가 없고, 공개 저장소라면 무료입니다.

| 항목 | 확인 주기 | 보내는 때 | 보내는 것 |
|---|---|---|---|
| 브리아셀 3상 관련 보도자료 | 3시간마다 | 3상 관련 보도자료가 새로 올라오면 (탑라인·중간분석이면 🚨 표시) | 제목 + 링크 |
| 오로라월드 미국 수입 B/L 건수 | 매월 15~17일 08:00 | 전월 데이터로 한 달에 한 번 | 전체 기간 월별 그래프 + 전월/전년 대비 |
| 미국 ISM 제조업 PMI | 매월 2~5일 09:30 | 새 발표가 반영되면 한 달에 한 번 (발표: 매월 첫 영업일 미국 동부 10시) | Trading Economics 10년 차트 캡처 + 요약 |
| 일본 공작기계 수주 | 매월 8~15일 16:30 | 새 발표가 반영되면 한 달에 한 번 (발표: 매월 중순쯤 일본 15시, 전월 속보) | 〃 |
| 구글 트렌드 비교군 10개 | 매주 월 09:00 | 매주 | 비교군 그래프 10장을 앨범 하나로 |

(시간은 모두 한국 시간. GitHub 예약 실행은 몇 분~수십 분 늦어질 수 있습니다.)

---

## 1. 텔레그램 봇 만들기 (5분)

1. 텔레그램에서 **@BotFather** 검색 → `/newbot` → 이름과 아이디(…bot으로 끝나야 함) 입력
2. BotFather가 주는 **토큰**(`123456789:ABC...` 형태)을 복사해 둡니다.
3. 방금 만든 봇과 대화를 열고 아무 메시지나 한 번 보냅니다. (안 보내면 봇이 나에게 말을 걸 수 없음)
4. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 엽니다.
   결과의 `"chat":{"id": 123456789 ...}` 숫자가 **채팅 ID**입니다.

## 2. GitHub 저장소 만들기

1. github.com → **New repository** → 이름 예: `data-tracker`
   - **Public 권장**: 공개 저장소는 Actions가 무료·무제한입니다.
     (토큰은 아래 Secrets에 들어가서 공개되지 않습니다. 공개되는 건 코드와 키워드 목록뿐입니다.)
   - Private로 해도 지금 주기(브리아셀 3시간마다 등)면 월 2,000분 무료 한도 안에 들어옵니다.
2. 이 폴더의 파일을 전부 업로드합니다. (웹에서 **Add file → Upload files**로 폴더째 끌어다 놓으면 됩니다.
   `.github` 폴더가 숨김 폴더라 안 보이면 터미널에서 `git push` 하세요.)
3. **Settings → Secrets and variables → Actions → New repository secret** 에서 두 개 추가
   - `TELEGRAM_BOT_TOKEN` = 봇 토큰
   - `TELEGRAM_CHAT_ID` = 채팅 ID
4. **Settings → Actions → General → Workflow permissions** 를 **Read and write permissions** 로 바꾸고 저장
   (보낸 기록을 `state/` 폴더에 저장해서 같은 알림을 두 번 보내지 않게 하기 위함)

## 3. 첫 실행 (테스트)

**Actions** 탭 → 왼쪽에서 워크플로 선택 → **Run workflow**
- `브리아셀 3상 감시`: "✅ 감시를 시작했어요" 메시지가 오면 정상. (첫 실행은 기존 보도자료를 기준으로만 저장)
- `오로라 미국 수입 (월간)`: force 체크 후 실행 → 그래프가 바로 옵니다.
- `미국 ISM 제조업 PMI (월간)`, `일본 공작기계 수주 (월간)`: force 체크 후 실행 → 각각 차트가 옵니다.
- `구글 트렌드 (주간)`: 실행 → 앨범이 옵니다.

실패하면 빨간 ✗ 를 눌러 로그를 확인하세요. 수집 실패는 텔레그램으로도 하루 1번 무음 알림이 갑니다.

## 설정 바꾸기 — `config.yaml`

- **구글 트렌드 키워드·국가·기간**: `trends.groups` 수정 (한 그룹 최대 5개)
  - 국가별 비교는 `geo: ["GB", "US"]`처럼 쓰고 키워드를 같은 개수만큼 반복합니다.
  - 기간 `timeframe`: `today 12-m`(1년), `today 5-y`(5년), `today 3-m`(3개월)
- **브리아셀 알림 기준**: `topline_patterns`(🚨 표시), `phase3_patterns`(3상 관련으로 볼 단어). 이 둘에 안 걸리는 보도자료는 보내지 않습니다.
- **실행 주기**: `.github/workflows/*.yml` 의 `cron` (UTC 기준, 한국 = UTC+9)

## 알아 둘 점

- **Trading Economics, 구글 트렌드**는 공식 무료 API가 없어 실제 브라우저로 페이지를 열어 화면을 캡처합니다.
  두 사이트가 자동 접속을 막으면 실패할 수 있고, 그때는 링크와 함께 실패 알림이 옵니다.
- 오로라 데이터는 importinfo 페이지가 그래프를 그릴 때 쓰는 공개 데이터(월별 B/L 건수)를 그대로 받아 그래프를 새로 그립니다.
- 공개 저장소가 60일 동안 아무 커밋이 없으면 GitHub가 예약 실행을 멈춥니다. 오로라·ISM·공작기계가 매달 기록을 커밋하므로 보통 문제없지만, 멈추면 Actions 탭에서 다시 켜면 됩니다.
